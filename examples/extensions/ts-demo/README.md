# ts-demo

A bones extension written in TypeScript: a square the arrow keys move, the same product as the Rust `game` template. It shows that the ABI is language-neutral in practice, and it is the starting point for a guest in TypeScript or JavaScript.

## Build and run

It needs Node.js 22.18 or later. The build tools come from npm into this directory; nothing is installed globally.

```sh
npm ci
npm test          # the message codec against wit/vectors/vectors.txt
npm run build     # dist/ts_demo.wasm, a component built with jco componentize
```

Copy `dist/ts_demo.wasm` into an engine's `extensions/` folder, with this directory's `bones.toml` beside the engine, or point `BONES_CONFIG` at it. A JavaScript component carries its own JS engine and is about 12 MB, so its first load takes longer than a Rust one. The `bones.toml` here raises `extension_load_timeout_ms` for that.

`jco componentize` downloads a prebuilt binary that does not exist for Windows on ARM64. Build there with an x64 Node.js, which runs under emulation.

## How it is made

| File | Is |
| --- | --- |
| `src/extension.ts` | The extension: the `extensionApi` exports, calling the `bones:extension/host-api` imports |
| `src/messages.ts` | Generated by `cargo xtask ts-codec` from `wit/wire-format.json`: a type and a field list for every core topic whose payload is a plain field list. Do not edit it |
| `src/wire.ts` | The codec that turns those field lists into bytes and back, following `wit/wire-format.md` |
| `build.mjs` | Strips the TypeScript types with Node's own `module.stripTypeScriptTypes`, then runs `jco componentize` against `wit/extension.wit` |
| `test/wire.test.ts` | Encodes and decodes every conformance vector of a plain topic and requires the exact bytes and values |

The imports follow jco's mapping of WIT to JavaScript. `bones:extension/host-api@1.0.0` is an ES module whose functions take and return `Uint8Array` for `list<u8>`. The exported interface `extension-api` is an object named `extensionApi`.

A topic whose payload is a tagged union or a counted sequence, such as `game-core/entity-op` or `ui/spec`, is not in `messages.ts`. Encode it by hand from `wit/wire-format.md`.
